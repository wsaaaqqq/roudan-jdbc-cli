# roudan-jdbc-cli 详细设计

## 1. 调用形式

```
roudan-jdbc-cli [全局选项] <子命令> [子命令选项]
```

每条命令一次调用、一次执行、一次输出，无交互模式。
AI 通过 subprocess 调用，读取 stdout 的 JSON 结果，错误通过 stderr 及退出码反馈。

---

## 2. 全局选项（连接配置）

支持两种配置模式，二选一：

### 模式A — 配置文件

```
roudan-jdbc-cli -c roudan-config.yaml query -s "SELECT 1"
```

`roudan-config.yaml` 格式：

```yaml
datasources:
  default:
    url: jdbc:mysql://localhost:3306/test
    user: root
    password: "123456"
    driver: com.mysql.cj.jdbc.Driver
    driverJar: /path/to/mysql-connector.jar
  otherdb:
    url: jdbc:postgresql://localhost:5432/test
    user: postgres
    password: "secret"
    driver: org.postgresql.Driver
    driverJar: /path/to/postgresql.jar
settings:
  showSql: false
  autoCommit: true
```

### 模式B — 命令行参数

```
roudan-jdbc-cli -u jdbc:mysql://localhost:3306/test -n root -p 123456 -d com.mysql.cj.jdbc.Driver -j mysql-connector.jar query -s "SELECT 1"
```

| 选项 | 说明 |
|------|------|
| `-c, --config <file>` | YAML 配置文件路径（模式A） |
| `-u, --url <jdbc-url>` | JDBC URL（模式B） |
| `-n, --user <username>` | 数据库用户名（模式B） |
| `-p, --password <password>` | 数据库密码（模式B） |
| `-d, --driver <class>` | JDBC 驱动类全限定名（模式B） |
| `-j, --driver-jar <path>` | 驱动 JAR 包路径（模式B） |
| `--datasource <name>` | 数据源名称，多数据源时指定，默认 `defaultDataSource` |
| `-o, --output <fmt>` | 输出格式：`json`(默认)、`csv`、`table` |
| `--no-header` | 查询结果不输出列头信息 |
| `--pretty` | 格式化 JSON 输出（默认紧凑一行） |

## 3. 子命令一览

| 命令 | 说明 | 对应 roudan-core API |
|------|------|---------------------|
| `query` | 执行 SELECT 查询 | `RD.query()` / `RD.namedQuery()` |
| `count` | 执行 SELECT COUNT | `executeCount()` |
| `modify` | 执行 INSERT/UPDATE/DELETE/DDL | `RD.modify()` / `RD.namedModify()` |
| `tables` | 列出数据库中所有表/视图 | JDBC 元数据 |
| `describe` | 查看表结构（列名/类型/主键） | JDBC 元数据 |
| `test` | 测试数据库连接可用性 | `Connection.isValid()` |

## 4. 子命令详细设计

### 4.1 `query` — 执行查询

```
# 命名参数
roudan-jdbc-cli query -s "SELECT * FROM T_USER WHERE age > :minAge" --named -a '{"minAge":18}' --limit 100

# 位置参数 + 分页
roudan-jdbc-cli query -s "SELECT * FROM T_USER WHERE age > ?" -a '[18]' --limit 100 --page 1 --size 20

# SQL 文件
roudan-jdbc-cli query -f "sql/user_list.sql" --named -a '{"deptId":"D01"}'
```

| 选项 | 说明 |
|------|------|
| `-s, --sql <sql>` | SQL 语句（与 `-f` 二选一必填） |
| `-f, --sql-file <path>` | SQL 文件路径 |
| `--named` | 使用命名参数 `:paramName`（默认 `?` 占位） |
| `-a, --args <json>` | 参数：JSON 数组（位置）或 JSON 对象（命名） |
| `--limit <n>` | 返回行数上限 |
| `--page <n>` | 分页-页码（从1开始，需配合 `--size`） |
| `--size <n>` | 分页-每页条数 |

**输出：**

```json
{
  "success": true,
  "rowCount": 42,
  "cols": ["ID", "NAME", "AGE"],
  "rows": [
    ["1", "张三", 25],
    ["2", "李四", 30]
  ],
  "timeMs": 15
}
```

### 4.2 `count` — 查询计数

```
roudan-jdbc-cli count -s "SELECT * FROM T_USER WHERE age > ?" -a '[18]'
roudan-jdbc-cli count -s "SELECT * FROM T_USER WHERE status = :st" --named -a '{"st":1}'
```

**输出：**

```json
{
  "success": true,
  "count": 1503,
  "timeMs": 8
}
```

### 4.3 `modify` — 执行写操作

```
# 命名参数 INSERT
roudan-jdbc-cli modify -s "INSERT INTO T_USER (id, name) VALUES (:id, :name)" --named -a '{"id":"U01","name":"王五"}'

# 位置参数 UPDATE
roudan-jdbc-cli modify -s "UPDATE T_USER SET name=? WHERE id=?" -a '["新名字","U01"]'

# DELETE
roudan-jdbc-cli modify -s "DELETE FROM T_USER WHERE id=?" -a '["U01"]'

# SQL 文件
roudan-jdbc-cli modify -f "sql/update.sql" --named -a '{"id":"U01","status":1}'

# DDL
roudan-jdbc-cli modify -s "CREATE TABLE T_LOG (id VARCHAR(32), msg TEXT)"
```

**输出：**

```json
{
  "success": true,
  "affectedRows": 1,
  "timeMs": 12
}
```

### 4.4 `tables` — 查看表列表

```
roudan-jdbc-cli tables
roudan-jdbc-cli tables --pattern "T_%"
```

**输出：**

```json
{
  "success": true,
  "tables": [
    {"name": "T_USER", "type": "TABLE"},
    {"name": "T_ORDER", "type": "TABLE"},
    {"name": "V_USER_ORDER", "type": "VIEW"}
  ],
  "timeMs": 5
}
```

### 4.5 `describe` — 查看表结构

```
roudan-jdbc-cli describe -t T_USER
```

**输出：**

```json
{
  "success": true,
  "table": "T_USER",
  "columns": [
    {"name": "ID", "type": "VARCHAR", "size": 32, "nullable": false, "pk": true},
    {"name": "NAME", "type": "VARCHAR", "size": 64, "nullable": true, "pk": false},
    {"name": "AGE", "type": "INTEGER", "size": 10, "nullable": true, "pk": false}
  ],
  "timeMs": 3
}
```

### 4.6 `test` — 连接测试

```
roudan-jdbc-cli test
```

**输出：**

```json
{
  "success": true,
  "message": "connection ok",
  "dbProduct": "MySQL 8.0.33",
  "timeMs": 120
}
```

## 5. 错误输出

所有命令错误时统一输出：

```json
{
  "success": false,
  "error": "SQLSyntaxErrorException: Table 'T_USERX' doesn't exist",
  "errorCode": "SQL_ERROR",
  "timeMs": 2
}
```

错误码枚举：

| errorCode | 说明 |
|-----------|------|
| `CONFIG_ERROR` | 配置文件加载/解析失败 |
| `DRIVER_ERROR` | JDBC 驱动加载失败 |
| `CONNECTION_ERROR` | 数据库连接失败 |
| `SQL_ERROR` | SQL 语法/执行错误 |
| `PARAM_ERROR` | CLI 参数不合法 |

退出码：成功=0，失败=1。

## 6. 模块架构

```
roudan-jdbc-cli
  ├── CLI入口 (Main + Picocli)
  │     ├── 解析全局选项
  │     ├── 路由子命令
  │     └── 输出 JSON
  ├── 配置加载 (ConfigLoader)
  │     ├── 读取 YAML 配置文件
  │     └── 合并命令行参数
  ├── 驱动加载 (DriverLoader)
  │     └── URLClassLoader 从指定 JAR 路径加载 JDBC 驱动
  ├── 数据源初始化 (DataSourceFactory)
  │     ├── 反射创建 Driver 实例
  │     ├── 构造 javax.sql.DataSource
  │     └── 注册到 RD.dataSourceConfig()
  └── 命令执行 (CommandExecutor)
        ├── QueryExecutor  → RD.query() / RD.namedQuery()
        ├── ModifyExecutor → RD.modify() / RD.namedModify()
        ├── CountExecutor  → executeCount()
        ├── MetaExecutor   → tables / describe (JDBC metadata)
        └── TestExecutor   → Connection.isValid()
```

## 7. 驱动加载机制

由于 JDBC 驱动 JAR 路径由用户指定，不能放在 classpath 中，需运行时动态加载：

```java
// 核心逻辑
URL[] urls = { new File(driverJarPath).toURI().toURL() };
URLClassLoader loader = new URLClassLoader(urls, ClassLoader.getSystemClassLoader());
Driver driver = (Driver) Class.forName(driverClassName, true, loader).getDeclaredConstructor().newInstance();
// 构造 DataSource 并注册 Driver
```

支持的 DataSource 类型（按优先级）：
1. HikariCP（若驱动 JAR 自带）
2. 驱动自带的 DataSource（如 MysqlDataSource、PGSimpleDataSource）
3. 通用的 `org.apache.commons.dbcp2.BasicDataSource` 或手写简单连接池

## 9. 设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 参数风格 | `?` 和 `:name` 两种 | 对应 roudan-core 两套 API（`RRSqlQuery` vs `RRSqlNamedQuery`） |
| 命名参数开关 | `--named` 显式指定 | `?` 和 `:name` 映射到不同 API，明确更可靠 |
| 参数传值 | JSON 字符串 | 命令行天然适合，AI 可精确构造 |
| 输出格式 | JSON（紧凑默认） | AI 解析最简便，`--pretty` 供人工调试 |
| 批量写 | 暂不纳入 v1 | CLI 单次调用场景下批次意义不大 |
| DDL | `modify` 子命令覆盖 | `CREATE TABLE` 也是写操作，不复增殖命令 |
| 无交互模式 | 每次调用一条命令 | CLI 供 AI 调用，非交互式 shell |
