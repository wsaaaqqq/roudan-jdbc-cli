# roudan-jdbc-cli 开发规划

> 记录项目整体开发思路、架构决策和计划。供 AI 了解项目全貌。
> 当前版本：v0.3.0 | 下一个里程碑：v0.4.0

## 1. 项目定位

JDBC 数据库 CLI 工具，AI agent 通过 subprocess 调用，stdout 输出 JSON，stderr 输出错误信息。

**一句话**：让 AI 能像敲命令一样操作任何 JDBC 数据库。

## 2. 技术栈

| 层面 | 选择 | 理由 |
|------|------|------|
| 语言 | Java 8 | 与 roudan-core 对齐 |
| 构建 | Maven | 标准 Java 构建工具 |
| CLI 框架 | Picocli 4.7.6 | 注解式子命令、自动 help、零 Spring 依赖 |
| YAML 解析 | SnakeYAML 2.0 | 标准 YAML 解析库 |
| JSON 序列化 | hutool-json 5.8.25 | 与 roudan-core 统一 hutool 生态 |
| JDBC 封装 | roudan-core 0.0.1 | `RD.query() / RD.modify() / RD.namedQuery()` |
| 代码精简 | Lombok 1.18.26 | `@Slf4j` |
| 日志 | slf4j-nop | AI 模式不需要日志输出 |

## 3. 打包方案

**方案 A：fat-jar + 启动脚本**（当前选择）

```
发布包结构：
roudan-jdbc-cli-1.0/
├── roudan-jdbc-cli.bat    # Windows 启动脚本
├── roudan-jdbc-cli        # Unix 启动脚本
└── lib/
    └── roudan-jdbc-cli.jar
```

使用 `maven-shade-plugin` 打 fat-jar，启动脚本包装 `java -jar` 调用，用户将其加入 PATH 后即可直接使用 `roudan-jdbc-cli` 命令。

## 4. CLI 设计

### 调用形式

```
roudan-jdbc-cli [连接选项] <子命令> [子命令选项]
```

### 配置三层发现（优先级递减）

1. **命令行参数**：`-u jdbc:... -n root -p xxx -d com.mysql.Driver -j ./driver.jar`
2. **环境变量**：`ROUDAN_JDBC_URL`, `ROUDAN_JDBC_USER`, `ROUDAN_JDBC_PASSWORD`, `ROUDAN_JDBC_DRIVER`, `ROUDAN_JDBC_DRIVER_JAR`, `ROUDAN_JDBC_DATASOURCE`
3. **配置文件**：`-c config.yaml` 或自动发现 `./roudan-config.yaml`

### 子命令

| 命令 | 功能 | 核心 API |
|------|------|----------|
| `query` | SELECT 查询 | `RD.query()` / `RD.namedQuery()` → `executeQuery().result()` |
| `count` | SELECT COUNT | `RD.query().executeCount()` |
| `modify` | INSERT/UPDATE/DELETE/DDL | `RD.modify()` / `RD.namedModify()` → `execute()` |
| `tables` | 列出表/视图 | JDBC `DatabaseMetaData.getTables()` |
| `describe` | 查看表结构 | JDBC `DatabaseMetaData.getColumns()` + `getPrimaryKeys()` |
| `test` | 连接测试 | `Connection.isValid()` |

### 参数风格

- **位置参数**（默认）：SQL 中用 `?` 占位，`-a '[val1, val2]'`
- **命名参数**（`--named`）：SQL 中用 `:paramName` 占位，`-a '{"key":"val"}'`

### 输出格式

默认 JSON 紧凑单行，支持 `--output json|json-pretty|csv|table` 以及 `--no-header`。

### page/limit 实现

采用**内存截取**（方案 A）：全量查询后在 Java 侧用 subList 截取。不改写 SQL，适合 CLI 场景的数据量级。

## 5. 关键架构决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 分页实现 | 内存截取 | CLI 数据量可控，不改写 SQL 更安全 |
| DataSource 优先级 | HikariCP > 驱动自带 > 手写 | 按设计文档第7节 |
| `--named` 显式指定 | 不加自动检测 | 避免 SQL 中 `?` 和 `:` 歧义 |
| DDL 归属 | `modify` 子命令覆盖 | 不复增殖命令 |
| 批量写 | v1 暂不纳入 | CLI 单次调用意义不大 |
| 退出码 | 0=成功, 1=失败 | 简单明确 |

## 6. 交付形态

项目同时产出两样东西：

### 6.1 二进制工具

- **GitHub Releases** 发布 fat-jar + 启动脚本 zip
- 用户下载解压 + 配置 PATH 即可使用
- 前置要求：Java 8+

### 6.2 OpenCode Skill

- `skill/SKILL.md` 是 opencode skill 主入口
- AI agent 加载 skill 后得知工具的安装方法和使用方式
- 安装方式：
  - 复制到 `~/.agents/skills/roudan-jdbc/SKILL.md`
  - 或通过 opencode.json 的 `skills.paths` 引用项目目录
  - 或通过 `skills.urls` 引用 GitHub raw 地址

Skill 跟代码同仓库，发布新版本时同步更新。

## 8. CI/CD 策略

```

```

```
checkout → setup-java 8 → mvn package → 组装 zip → GitHub Release
```

### 第2周：数据导入导出 (Day 6-10)

| Day | 任务 | 交付物 | 说明 |
|-----|------|--------|------|
| D6 | `rd import` — CSV 导入 | `ImportCommand.java` | `rd import -t T_USER -f data.csv`；支持 CSV 首行作为列名；自动推断类型；内部用 `PreparedStatement` 批量 INSERT；可选 `--batch 100` 控制批次 |
| D7 | `rd import` — JSON 导入 | `ImportCommand.java` 增强 | `rd import -t T_USER -f data.json -f json`；JSON 格式：`[{"col":"val"}, ...]` 或 `{"cols":["col1"],"rows":[["val"]]}`；自动处理嵌套 JSON |
| D8 | `rd export` — CSV/JSON 导出 | `ExportCommand.java` | `rd export -s "SELECT * FROM T_USER" -o csv > users.csv`；支持 --limit/--page/--size；JSON 输出直接进 stdout，CSV 自动文件写入 |
| D9 | `rd exec` 事务模式增强 | `ExecCommand.java` 增强 | 新增 `--mode transaction|auto` 模式：transaction=当前行为（全部成功 commit，失败 rollback），auto=每个语句独立提交（类似 psql 默认行为）；每条语句结果独立输出 |
| D10 | `rd exec` + `rd import` 集成测试 | 测试代码 | 20+ 新测试用例覆盖 import 文件格式、数据类型边标、exec 事务回滚/提交、exec auto 模式、大文件 import |
