# roudan-jdbc-cli 设计概要

## 项目定位
roudan-jdbc-cli 是一个命令行数据库操作工具，供 AI Agent 通过 subprocess 调用，
基于 [roudan-core](https://github.com/wsaaaqqq/xdb) 轻量级 JDBC 框架构建。

## 核心功能
- 可配置 JDBC 数据库连接参数（url / user / password / driver）
- 支持外部 JDBC 驱动 JAR 动态加载（URLClassLoader）
- 提供 CLI 子命令：query（查询）、modify（增删改）、count（计数）、tables（表列表）、describe（表结构）、test（连接测试）
- 支持 `?` 位置参数和 `:name` 命名参数两种 SQL 风格
- 支持 SQL 文件执行
- 输出 JSON 格式，便于 AI 解析

## 技术选型
- **语言**: Java 8
- **构建**: Maven
- **CLI 框架**: Picocli
- **核心依赖**: `io.github.wsaaaqqq:roudan-core:0.0.1`
- **基础工具**: hutool-core 5.8.25, Lombok, Slf4j
